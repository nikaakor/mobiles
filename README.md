

# 🚀 Smart Event Flow Monitoring System

**Smart Event Flow** — це мобільний додаток на Flutter для моніторингу подій у реальному часі. Проєкт розробляється в межах університетського курсу з IoT та Flutter.

## 📋 Лабораторна робота №3: Логіка та локальне сховище

У цій ітерації додаток отримав "мозок" — реалізовано систему автентифікації, валідації та повноцінного керування даними користувача (CRUD).

### ✨ Реалізований функціонал:

* **Локальна автентифікація:** Реєстрація та вхід користувачів з використанням `SharedPreferences`.
* **Рольова модель:** Підтримка двох типів акаунтів:
* **Організатор:** може вказувати назву події та керувати моніторингом.
* **Відвідувач:** має доступ до загальної інформації.


* **Повний CRUD профілю:** * **Create:** Створення акаунта з валідацією полів.
* **Read:** Відображення детальної інформації (email, телефон, вік, гендер).
* **Update:** Редагування особистих даних через діалогові вікна.
* **Delete:** Безповоротне видалення акаунта зі сховища.


* **Валідація:** Перевірка коректності email, довжини пароля та обов'язкових полів за допомогою регулярних виразів.

---

### 🏗 Архітектура проекту

Проєкт побудований на принципах чистої архітектури, що дозволяє легко замінити локальне сховище на зовнішній API:

* **Models (`/lib/models/`):** Об'єктно-орієнтована модель `UserModel` з методами `toMap`, `fromMap` та `copyWith`.
* **Domain (`/lib/domain/`):** Абстрактні інтерфейси (Repository Pattern) та логіка валідації.
* **Data (`/lib/data/`):** Реалізація репозиторію через `SharedPreferences`. Дані зберігаються у форматі JSON-списків.
* **Screens (`/lib/screens/`):** UI-шар на базі `StatefulWidget` для динамічного оновлення стану.

---

### 🛠 Технологічний стек:

* **Framework:** Flutter 3.33+ (Paid Tier)
* **Language:** Dart
* **Storage:** `shared_preferences`
* **Linter:** Strict Analysis (з обробкою `async gaps` для безпеки `BuildContext`).
