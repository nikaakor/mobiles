# 🛰️ Smart Event Flow Monitoring System

Мобільний додаток для інтелектуального моніторингу масових заходів та управління станом локацій через IoT-інфраструктуру.

## 🌟 Про проєкт
Smart Event Flow — це інструмент для адміністраторів та організаторів, що дозволяє в реальному часі бачити повну картину того, що відбувається на локації. Додаток агрегує дані з датчиків комфорту, систем підрахунку відвідувачів та AI-аналітики.

## 🚀 Основні можливості
* **Live Dashboard** — моніторинг черг, рівня шуму та активності зон.
* **Air Quality Control** — відстеження рівня CO2 та свіжості повітря в залах.
* **AI Analytics** — аналіз середнього настрою аудиторії та демографічного складу (стать/кількість людей).
* **Smart Alerts** — миттєві сповіщення про критичні зміни (наприклад, низький рівень залишку їжі в трапезній 🥪).
* **Interactive UX** — сучасний інтерфейс з градієнтами, Hover-ефектами та повною адаптивністю під різні екрани.

## 🛠 Технічний стек
* **Framework:** Flutter (Material 3)
* **Language:** Dart
* **Architecture:** Component-based UI (Reusable Widgets)
* **Navigation:** Named Routes
